¿Qué es HTML?

HTML es el lenguaje de marcado que organiza el contenido de una página. Sus etiquetas indican al navegador qué es un título, texto, enlace o imagen; no es un lenguaje de programación.

Etiquetas principales

  • <html> raíz del documento
  • <head> metadatos
  • <body> contenido visible
  • <h1> título principal
  • <p> párrafo
  • <a> enlace; usa href
  • <img> imagen; usa src y alt
  • <div> contenedor

Los atributos agregan información a una etiqueta, por ejemplo href. Muchas etiquetas se abren y cierran: <p>texto</p>.

¿Qué es Jinja2?

Jinja2 es un motor de plantillas para Python. Permite generar HTML dinámico al insertar datos, repetir contenido y mostrar partes de una página según ciertas condiciones.

Marcas de plantilla

  • {{ "{{ nombre }}" }} muestra una variable
  • {% raw %}{% if %}{% endraw %} condición
  • {% raw %}{% for %}{% endraw %} ciclo
  • {% raw %}{% extends %}{% endraw %} herencia
  • {% raw %}{% block %}{% endraw %} sección reemplazable

La expresión {{ "{{ nombre }}" }} muestra el valor de una variable.

¿Qué es CSS?

CSS significa hojas de estilo en cascada. Describe cómo se presenta el HTML: colores, tamaños, espacios y distribución. El navegador aplica sus reglas a los elementos seleccionados.

  • Selector: elige los elementos
  • Propiedad: indica qué cambiar
  • Valor: define el nuevo estilo

CSS no usa atributos: color y margin son propiedades.

Propiedades comunes

Una propiedad CSS controla un aspecto visual del elemento. Se escribe dentro de una regla, seguida de dos puntos y del valor que quieres aplicar.

  • color color del texto
  • font-size tamaño de letra
  • background-color color de fondo
  • margin espacio exterior
  • padding espacio interior
  • border borde del elemento

p { color: teal; }
El selector p recibe la propiedad color.

¿Qué es SQL?

SQL es un lenguaje para consultar y administrar bases de datos relacionales, donde la información se organiza en tablas. Sus comandos permiten buscar, agregar, modificar y estructurar datos.

Comandos principales

  • SELECT consulta
  • INSERT agrega filas
  • UPDATE modifica datos
  • DELETE elimina filas
  • CREATE crea objetos
  • ALTER cambia tablas
  • DROP elimina objetos
  • WHERE filtra resultados

SELECT nombre FROM alumnos;
Usa WHERE al actualizar o borrar.

¿Cómo trabajan juntas?

HTML organiza el contenido con etiquetas. CSS define su apariencia con propiedades. Jinja2 combina plantillas con datos y SQL consulta y organiza la información en bases de datos.
